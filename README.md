# MELTING POINT

AI 캐릭터 채팅 페어 홈페이지입니다. AI 생성물이 사용되었습니다.

## GitHub Pages 게시

저장소 Settings → Pages에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택합니다.

게시 주소: https://brutaltanuki.github.io/meltingpoint/

## 수정

- `index.html`: 화면, 스타일, 캐릭터 소개, 음악 플레이어, 해파리 수조, 가챠
- `pair/`: 도감과 캐릭터 사진
- `gacha/`: 배경을 제거한 캡슐·상품 이미지
- 나머지 이미지·SVG: 메인 화면, INFO, 음악 버튼, 배너

별도 설치나 빌드 없이 동작하는 정적 사이트입니다. 음악은 YouTube, 글꼴은 외부 CDN을 사용합니다.
가챠 결과와 수조 상태는 새로고침 시 초기화됩니다.
